# المساعد الذكي للمدرسة

تطبيق Streamlit بسيط لأولياء أمور:
ابتدائية الرياض الثانية للبنات وابتدائية تحفيظ القرآن 17.

## النشر
1. ارفع الملفات إلى GitHub repository.
2. افتح Streamlit Community Cloud واربط المستودع.
3. اختر `app.py` كملف التشغيل.
4. في Secrets أضف:
   OPENAI_API_KEY = "ضع_مفتاحك_هنا"
5. Deploy.

مهم: لا تضع مفتاح OpenAI API داخل app.py أو GitHub.
